# Privacy Policy

**Neopets Companion** does not collect, store, or transmit any personal data.

## Data Collection

This extension:

- Stores activity completion timestamps and counters locally using Chrome storage
- Does **not** collect usernames, passwords, emails, or account identifiers
- Does **not** transmit any data to external servers

## Website Interaction

The extension runs only on `neopets.com` pages to detect activity completion and cooldowns.

## Third Parties

No data is shared with third parties.

## Changes

This policy may be updated if the extension gains new features that affect data handling.
