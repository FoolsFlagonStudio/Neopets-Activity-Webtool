# Neopets Activity Tracker

A browser extension that helps track Neopets activities, cooldowns, and daily resets,
and notifies you when activities are available again.

## What this does
- Tracks activity availability (daily resets, cooldown timers)
- Provides quick links to activities
- Sends optional notifications
- Reward trackers (just for fun), logged automatically from result pages:
  - NeoCola Machine - tokens used, NP won, prize/transmog breakdown, stats per token/flavor/presses
  - Alien Aisha Vending Machine - Nerkmids used, NP won, Gross Food / Nerkmid / Faerie / Paint Brush
    rates vs published odds, stats per Nerkmid type
- Optional form prefill for both machines (NeoCola: first token, Dehydrated H20, 3 presses;
  Vending: first option in each dropdown) - you still press submit yourself
- Does NOT automate gameplay or perform actions

## Disclaimer
This project is not affiliated with Neopets.
It does not automate gameplay or bypass site mechanics.
All actions are performed manually by the user.
